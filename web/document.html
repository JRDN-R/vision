    A quick start

    Vision v{{VISION_VERSION}}

    1. Add modules. Use Add to board to choose images, videos, audio, documents, or clipboard content. Pasted text becomes an editable text node. Drop files onto blank board space to give each file its own module, or onto an existing module to attach them there. Paste inside a text field keeps normal text editing.
    2. Connect the sequence. Drag from either connector, or click the two connectors in turn. Grab either end of an existing wire to move it; releasing on empty space keeps its original connection. Branches run together. Enable an IF condition in Paths when needed, or tap an IF label to turn it off. Paths may merge; loops are blocked.
    3. Caption and annotate. Select a module to edit its text and caption. Choose an arrow, circle, box, or pen and draw on an image. V selects and moves marks; the eraser removes them.
    4. Record and transcribe. The board microphone lets you choose FUPCJ Server Whisper or Gemini for new recordings and audio imports. Stop recording to create a module and fill its text with the transcript. Gemini access requires account approval. Keep the page open until audio is accepted by FUPCJ Server, then FUPCJ Server can finish in the background.
    5. Add video. Add a video module to use the connected FUPCJ Server for timestamped screenshots, audio sections, and a small playable preview. New video uploads require the current FUPCJ Server and support up to 100 MB. The preview stays on FUPCJ Server; the original upload is removed after processing. Existing video attachments can also use the bundled browser tools.
    6. Export and save. Export packages the module instructions and evidence for an AI. Save project downloads an editable project with its board and pending jobs. The project control shows browser and FUPCJ Server save status. Keep a downloaded project copy for another device or browser. Original videos are not included in editable saves or AI exports. Completed transcripts replace queued audio.

    Use Undo/Redo on the left toolbar, Ctrl / ⌘ + Z, or Ctrl / ⌘ + Shift + Z. With the board focused, Tab moves to the next module and Shift + Tab moves back. Text fields keep their normal keyboard controls.
