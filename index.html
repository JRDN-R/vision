A quick start

  1. Add images. Drag files from your computer, use the + button, or paste copied images with Ctrl / ⌘ + V. Paste is captured anywhere in the app, including the caption field.
  2. Connect the sequence. Drag an image’s right dot onto another image’s left dot. You can also click the two dots in turn. Each image has one previous and one next image. Reconnecting replaces occupied connections. Loops are blocked.
  3. Caption and annotate. Select an image to write a caption in the side panel. Choose an arrow, circle, box, or pen and draw right on the image. V selects and moves marks; the eraser removes them.
  4. Attach files. Drop audio, video, PDFs, spreadsheets, text, or extra images onto an existing image. Use the + button or drop onto blank board space to create a new main image. Audio/video files offer optional Gemini transcription; a transcript is added as another file.
  5. Export. With no attachments, get only numbered PNGs. With attachments, get numbered block folders, originals, marked images, captions, all files, the main AI prompt, and an ordered manifest. Every image is included. Edit the main prompt in the side panel.
  6. Save your work. Save project downloads a portable .vision.json file with the original images, captions, marks, attachments, the main prompt, connections, and board view. Open project restores it. You can also reopen a project ZIP exported with attachments. Save before closing; the app does not upload or autosave your work.

Original aspect ratios are preserved. Captions extend downward. Animated images use a still frame. Editing, file storage, and export work offline. Transcription needs internet and your Gemini API key. The built-in video decoder adds about 43 MB to this single HTML file.
